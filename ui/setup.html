ComfyUI 연결

ComfyUI의 실제 모델 폴더 경로를 입력할 필요는 없습니다. 연결된 ComfyUI가 인식하는 Anima 모델·텍스트 인코더·VAE·LoRA 목록을 API로 자동 조회합니다. 다른 PC나 사용자 지정 포트도 주소를 직접 입력하면 사용할 수 있습니다.
아직 확인하지 않았습니다.
자동 찾기는 이 PC의 일반적인 ComfyUI 포트만 확인합니다. 원격/특수 포트는 주소를 직접 입력하세요.

캐릭터 연결

Wayward의 캐릭터 ID와 Anima 캐릭터 LoRA를 연결합니다. 설정을 삭제해도 게임 저장 데이터는 변경하지 않습니다.

Wayward 이미지팩

AI 이미지만 사용할 캐릭터는 기존 정적 이미지팩을 비활성화할 수 있습니다. 파일은 삭제하지 않고 _disabled-imagepacks 아래로 이동하며 언제든 복원할 수 있습니다.

작업 제어

불러오는 중…
현재 작업 취소는 이 백엔드가 만든 ComfyUI 작업만 대상으로 합니다. 수동 ComfyUI 작업이 함께 실행 중이면 안전을 위해 실행 중 샘플러는 강제 중단하지 않습니다. 게임/브라우저를 닫아도 AI 서버는 계속 실행됩니다. 서버가 꺼진 뒤에는 이 페이지를 열 수 없으므로 Wayward-Anima-Server.cmd에서 실행 상태 확인·시작·종료·재시작을 할 수 있습니다.
