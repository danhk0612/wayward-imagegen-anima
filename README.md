# wayward-imagegen-anima

An Anima-focused fork/adaptation of Wayward's local `wayward-imagegen` backend.

Goals:

- Run Wayward image generation through local ComfyUI.
- Use an Anima checkpoint as the primary image model.
- Apply per-character Anima LoRAs.
- Keep character-specific base prompts / trigger words separate from scene prompts generated by Wayward.
- Preserve Wayward's existing image generation API so the game does not need to be modified just to use the Anima backend.

The original image-generation backend expects Wayward to request images for existing game characters. This repository focuses first on replacing/regenerating those character images in real time. Adding a completely new playable Wayward character is a separate game-side task.
